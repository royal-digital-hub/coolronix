# Coolronix

Next.js App Router website for Coolronix AC repair and services in Hyderabad.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm start
```

Production domain: https://coolronix.in


Business updates included: Pre-Piping is a featured service; booking CTA added; specified service warranties added without inventing warranty terms for Pre-Piping.
